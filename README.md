# CleverGrid 🔍

> 一款基于 Web 端的推理解谜游戏

CleverGrid 是一项专注于叙事驱动与推理解谜的独立游戏项目。在这个由线索与逻辑交织的网络中，玩家将体验到深度的解谜乐趣。游戏完全基于 Web 平台开发，无需复杂的安装配置，打开浏览器即可随时随地进入推理世界。

## 🎮 游戏特色

* **深度推理解谜**：将严密的逻辑推理与叙事线索深度结合，挑战玩家的观察力与碎片信息整合能力。
* **沉浸式非线性叙事**：玩家的选择和推理过程将直接影响故事走向与案件的最终还原。
* **Web 原生体验**：轻量级前端架构，配合精心设计的 UI/UX 交互，带来流畅的点按反馈与跨平台支持。

## 🛠️ 技术栈

本项目主要采用前端原生技术及现代叙事引擎框架进行开发：

* **HTML5 / CSS3**：构建游戏的基础结构、界面布局与视觉呈现。
* **JavaScript**：处理游戏的核心逻辑、状态管理与交互控制。
* **Twine & SugarCube**：作为底层框架支持复杂的非线性文本逻辑跳转与宏命令扩展。

## 🚀 快速开始

本项目为前端静态项目，无需配置复杂的本地环境，运行非常简单：

1.  克隆本仓库到你的本地设备：
    ```bash
    git clone [https://github.com/NoireCase/CleverGrid.git](https://github.com/NoireCase/CleverGrid.git)
    ```
2.  进入项目目录：
    ```bash
    cd CleverGrid
    ```
3.  直接使用任意现代浏览器（推荐 Chrome 或 Edge）双击打开 `index.html` 即可运行游戏。

*(注：如果后续引入了更多外部资源请求，建议使用 VS Code 的 Live Server 等本地服务器插件打开以避免跨域限制)*

## 📁 目录结构

* `index.html` —— 游戏的主入口页面文件。
* `data.js` —— 存储游戏的核心数据、线索逻辑配置及自定义脚本。
* `.github/workflows/` —— 包含项目的自动化 CI/CD 工作流配置（如自动化部署页面）。
* `LICENSE` —— 开源许可证文件。
